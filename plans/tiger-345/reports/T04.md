## Kết quả

- **Hành vi đã chạy được**:
  - Triển khai chuẩn hóa Edge Function Gateways:
    - `/public-api`: Cho phép truy cập ẩn danh (Guest role, `userId = null`). Nhận diện đúng token khách hàng hợp lệ (`role: 'customer'`). Khi cung cấp token lỗi/hết hạn, trả về 401 `AUTH_REQUIRED` ngay lập tức, tuyệt đối không tự động giáng cấp ngầm thành guest (bảo toàn bất biến V05).
    - `/customer-api`: Bắt buộc Bearer JWT của khách hàng. Xác thực và trả về dữ liệu `/me`. Kiểm tra cờ `deletion_requested_at`: nếu khách hàng đã yêu cầu xóa tài khoản, từ chối ngay lập tức với 403 `FORBIDDEN`.
    - `/admin-api`: Yêu cầu tài khoản xác thực và kiểm tra trạng thái `admin_profiles.active = true` trực tiếp trên database ở MỌI request. Nếu admin bị vô hiệu hóa (`active = false`), từ chối ngay với 403 `FORBIDDEN` (bảo toàn bất biến V25). Chặn người dùng thường truy cập trái phép.
  - Bộ giới hạn tần suất nguyên tử (Atomic Rate Limiter):
    - Dựa trên bảng PostgreSQL `rate_limit_buckets` với câu lệnh `INSERT ... ON CONFLICT (bucket_hash, window_start) DO UPDATE SET count = rate_limit_buckets.count + 1`.
    - Băm địa chỉ IP với secret salt (`hashWithSalt`) bằng SHA-256; không lưu hoặc log địa chỉ IP thô.
    - Khi vượt ngưỡng tần suất (rate limit exceeded), trả về HTTP 429 `RATE_LIMITED` kèm header `Retry-After` chuẩn.
  - Chuẩn hóa Transport Envelope & Xử lý lỗi:
    - Success envelope: `{ data: T, request_id: string }`.
    - Error envelope: `{ error: { code: string, message: string, field_errors?: Record<string, string[]> }, request_id: string }`.
    - Giới hạn kích thước payload 64KB cho mọi request.
    - Che giấu và lọc sạch stack traces, chi tiết SQL và thông tin nhạy cảm khỏi log và response trả về cho client.
  - Frontend Client Runtime & Auth State:
    - `src/lib/api/types.ts` & `src/lib/api/client.ts`: Phân loại lỗi mạng (`NetworkError`), timeout (`TimeoutError`), và lỗi API (`ApiError`); tự động đính kèm `X-Request-Id` và Bearer token nếu đã đăng nhập; không tự động retry các mutation với key mới.
    - `src/features/auth/`: Cung cấp `AuthContext`, `AuthProvider`, `useAuth` phản ứng với phiên đăng nhập Supabase và tải thông tin vai trò/hồ sơ (`guest` / `customer` / `admin`).
    - `src/app/providers.tsx`: Bọc ứng dụng trong `AppProviders` tại `src/App.tsx`.
    - Client production build xác nhận không chứa bất kỳ secret key (`service_role`) hay module máy chủ nào.

- **Files/migrations/endpoints chính**:
  - `supabase/functions/_shared/types.ts`: Error codes và transport envelopes.
  - `supabase/functions/_shared/cors.ts`: CORS headers và OPTIONS preflight handler.
  - `supabase/functions/_shared/errors.ts`: `AppError` và bộ chuẩn hóa `toErrorResponse`.
  - `supabase/functions/_shared/request.ts`: Request ID, client IP extraction, 64KB payload validation.
  - `supabase/functions/_shared/crypto.ts`: Salted SHA-256 semantic hashing và signed token utility với kid/expiry.
  - `supabase/functions/_shared/rate-limit.ts`: Atomic PostgreSQL-backed rate limiter.
  - `supabase/functions/_shared/auth.ts`: Middleware xác thực danh tính Public, Customer, Admin.
  - `supabase/functions/public-api/index.ts`: Public API Edge Function Gateway.
  - `supabase/functions/customer-api/index.ts`: Customer API Edge Function Gateway.
  - `supabase/functions/admin-api/index.ts`: Admin API Edge Function Gateway.
  - `src/lib/api/types.ts`: Client API types và error classes.
  - `src/lib/api/client.ts`: Client API fetch wrapper.
  - `src/features/auth/AuthContext.tsx`, `AuthProvider.tsx`, `useAuth.ts`, `index.ts`: React Auth feature module.
  - `src/app/providers.tsx`: Root providers wrapper.
  - `tests/server/rate-limit.test.ts`: Server crypto & atomic rate limiter test suite.
  - `tests/integration/auth.test.ts`: Edge Function gateway security integration test suite.
  - `tsconfig.server.json` & `vitest.server.config.ts`: Server type checking và test configuration.

- **Acceptance criteria đã đạt (liệt kê ID Vxx và case task)**:
  - **V05**: Guest được gọi endpoint public hợp lệ; Bearer token sai hoặc hết hạn trả về 401 `AUTH_REQUIRED`, không tự động giáng cấp thành guest.
  - **V25**: Admin vô hiệu hóa (`active = false`) bị chặn 403 `FORBIDDEN` ngay lập tức trên mọi request.
  - Khách hàng đã yêu cầu xóa tài khoản (`deletion_requested_at IS NOT NULL`) bị chặn 403 `FORBIDDEN`.
  - Rate limit nguyên tử qua database trả về 429 `RATE_LIMITED` và header `Retry-After`.
  - Typecheck server thực tế (`npm run typecheck:server`) 0 lỗi.
  - Client production build (`npm run build`) hoàn tất sạch sẽ, bundle không chứa secrets.
