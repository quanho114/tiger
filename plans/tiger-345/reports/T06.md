## Kết quả

- Hành vi đã chạy được:
  - Admin tạo bàn ăn kèm sinh tự động token QR 32 bytes ngẫu nhiên bảo mật cao (`base64url`). Plaintext raw token và QR URL (`/table/${rawToken}`) chỉ trả về đúng 1 lần duy nhất lúc tạo hoặc xoay mã; database chỉ lưu SHA-256 hex digest (`token_hash`).
  - RPC PostgreSQL giao dịch `public.open_table_visit`: Row-lock bảng `dining_tables`, kiểm tra active, tạo phiên phục vụ với `status = 'open'`, `capability_epoch = 1`, `version = 1`. Chống mở trùng phiên bằng row-lock và partial unique index `idx_table_visits_single_open`. Concurrency race test chứng minh 2 request mở đồng thời thì duy nhất 1 request thành công, request còn lại nhận 409 `VISIT_ALREADY_OPEN`.
  - Trigger PostgreSQL `trg_dining_tables_deactivate_guard` (`check_dining_table_deactivation`): Chặn deactive bàn ăn (`active: false`) khi bàn đang có phiên phục vụ mở, trả về lỗi P0005 (`TABLE_HAS_ACTIVE_VISIT`).
  - RPC PostgreSQL `public.rotate_table_qr`: Vô hiệu hóa token QR cũ, kích hoạt token mới, tự động tăng `capability_epoch` và `version` trên phiên phục vụ đang mở (nếu có) để thu hồi toàn bộ capability token cũ trong 1 atomic transaction.
  - RPC PostgreSQL `public.close_table_visit`: Kiểm tra toàn bộ đơn hàng thuộc phiên phải ở trạng thái kết thúc (`completed`, `cancelled`) và đã thanh toán (`payment_status != 'unpaid'`). Nếu còn đơn chưa thanh toán/chưa xong, trả về 409 `VISIT_NOT_SETTLED`. Khi đóng thành công, cập nhật `closed_at = now()`, tăng epoch để vô hiệu hóa capability.
  - Public API `POST /tables/resolve`: Rate limit 60 req/phút/IP, băm SHA-256 token đầu vào, xác minh trạng thái active của bàn và QR trong DB, kiểm tra phiên mở, sinh token HMAC-SHA256 visit capability có chữ ký số (TTL 4 giờ, server key ID `kid: 'v1'`).
  - Module `supabase/functions/_shared/capability.ts`: Cung cấp hàm sinh và xác minh capability token 2 lớp (xác minh chữ ký số + expiration bằng HMAC và đối soát trực tiếp trạng thái live PostgreSQL).
- Files/migrations/endpoints chính:
  - `supabase/migrations/20260919000003_table_visits_and_capabilities.sql` (trigger deactivation guard, RPC open_table_visit, close_table_visit, rotate_table_qr).
  - `supabase/functions/_shared/capability.ts` (engine sinh và xác thực visit capability token 2 lớp).
  - `supabase/functions/_shared/crypto.ts` (sha256, generateSecureToken, HMAC signing/verification).
  - `supabase/functions/public-api/index.ts` (`POST /tables/resolve`).
  - `supabase/functions/admin-api/index.ts` (`GET /tables`, `POST /tables`, `PATCH /tables/:id`, `POST /tables/:id/qr`, `POST /tables/:id/visits`, `GET /visits/:id`, `POST /visits/:id/close`).
  - `tests/server/capability.test.ts` (unit tests xác minh capability, expiration, epoch revocation, QR rotate revocation, table deactivation).
  - `tests/integration/tables.test.ts` (integration tests trọn vẹn lifecycle bàn, QR rotation, concurrency race condition, trigger guard, visit settlement).

  - V08 (Table Concurrency & State Invariants): Mở đồng thời 2 phiên trên cùng 1 bàn chỉ 1 phiên thành công (409 VISIT_ALREADY_OPEN); không thể deactive bàn có phiên mở (409 TABLE_HAS_ACTIVE_VISIT); không thể đóng phiên khi còn order unpaid (409 VISIT_NOT_SETTLED); version mismatch trả 409 VERSION_CONFLICT.
