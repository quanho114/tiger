## Kết quả

- **Hành vi đã chạy được**:
  - Triển khai Public API Endpoints tại Edge Function Gateway (`supabase/functions/public-api/index.ts`):
    - `GET /functions/v1/public-api/menu`:
      - Truy vấn danh mục hoạt động (`WHERE active = true ORDER BY sort_order ASC, name ASC`).
      - Truy vấn món ăn đã xuất bản trong danh mục hoạt động (`WHERE c.active = true AND m.published = true`).
      - Lọc theo chế độ dùng bữa qua query param: `?mode=dine_in` (`allow_dine_in = true`) hoặc `?mode=delivery` (`allow_delivery = true`).
      - Lọc theo danh mục qua query param: `?category=<slug_hoặc_id>`.
      - Món tạm hết (`available = false`) vẫn được giữ trong response kèm cờ `available: false` và `is_available: false` để client hiển thị trạng thái disabled/badge "Tạm hết", ngăn khách thêm vào giỏ. Món unpublish hoặc thuộc danh mục inactive bị loại bỏ hoàn toàn từ tầng truy vấn SQL.
      - Loại bỏ toàn bộ các trường nội bộ/admin khỏi DTO trả về cho khách (không rò rỉ cờ admin, internal notes, audit metadata).
      - Thiết lập HTTP Safe Caching: Header `Cache-Control: public, max-age=30, stale-while-revalidate=60`.
    - `GET /functions/v1/public-api/settings`:
      - Trả về thông tin công khai của nhà hàng: tên, hotline, zalo, facebook, maps_url, địa chỉ, timezone, trạng thái nhận đơn (`accepting_orders`, `accepting_dine_in_orders`, `accepting_delivery_orders`), cờ đặt bàn (`booking_enabled`), đơn giao tối thiểu (`min_delivery_order_vnd`), chính sách đặt bàn (`reservation_policy`), giờ mở cửa hoạt động (`business_hours`), ngày đóng cửa (`business_closures`), khu vực giao hàng (`delivery_zones`), và khu vực chỗ ngồi (`seating_areas`).
      - Cache-Control: `public, max-age=30, stale-while-revalidate=60`.
  - Frontend Catalog State Management (`src/features/catalog/`):
    - `CatalogContext` & `CatalogProvider`: Quản lý danh mục món ăn, danh sách món, món đặc sắc (`featuredItems`), cấu hình nhà hàng (`settings`), các cờ trạng thái `isLoading`, `isError`, `error`, và các hàm tải lại `refetchMenu` / `refreshMenu`, `refetchSettings` / `refreshSettings`.
    - Tải đồng thời menu và settings qua `Promise.all` với cờ `isMounted` an toàn, ngăn race condition và cảnh báo render.
    - Adapter tương thích ngược (`toLegacyMenuItem`) chuyển đổi dữ liệu database schema sang thuộc tính UI, tương thích hoàn toàn với `CartDrawer` và các component hiện có.
    - Xử lý lỗi trung thực (Truthful Error Handling): Khi API gặp sự cố hoặc timeout, hiển thị giao diện báo lỗi rõ ràng kèm nút thử lại (`Thử tải lại`), tuyệt đối không tự động sinh dữ liệu mock giả tạo thành công.
    - Fallback thông tin liên hệ ngoại tuyến (`getSiteInfo` trong `src/data/site.ts`): Cung cấp hotline và địa chỉ khẩn cấp để gọi trực tiếp khi mất kết nối, không cho phép thanh toán hoặc đặt món giả khi offline.
  - Tích hợp giao diện người dùng công khai:
    - `MenuPage`: Kết nối dữ liệu live từ `useCatalog()`. Hỗ trợ chuyển đổi chế độ Tại quán / Giao tận nơi (`?mode=delivery`), chọn danh mục (tab "Tất cả món" + danh mục động), tìm kiếm món thời gian thực, 8 thẻ skeleton khi tải, banner thông báo lỗi và disabled state cho món "Tạm hết".
    - `HomePage`: Hiển thị danh sách món nổi bật (`featuredItems`) lấy từ database thật theo `featured_rank`.
    - `LocationPage` & `Footer`: Đồng bộ hotline, địa chỉ, liên kết mạng xã hội và giờ hoạt động từ `settings`.
    - `ContactHub`: Tự động nhận diện trợ lý tự động ("Giải đáp tự động Tiger 345"), tính toán khoảng giá thực tế từ menu database, đồng bộ hotline và địa chỉ.

  - `src/pages/HomePage.tsx`: Giao diện trang chủ tích hợp món nổi bật và giờ hoạt động từ database.

  - `tests/integration/catalog.test.ts`: Integration test suite kiểm tra DB query, active/inactive categories, published/unpublished items, unavailable items ("Tạm hết"), mode filters và 30s cache headers.
  - `tests/e2e/catalog.spec.ts`: End-to-end test suite kiểm tra hiển thị menu, chuyển đổi chế độ, tìm kiếm thời gian thực, và giao diện báo lỗi trung thực khi API fail.

- **Acceptance criteria đã đạt (liệt kê ID Vxx và case task)**:
  - **V06**: Menu trả về danh mục hoạt động (`active = true`), món đã xuất bản (`published = true`). Món tạm hết (`available = false`) hiển thị cờ disable / badge "Tạm hết" rõ ràng trên UI, không cho phép đặt giao. Món unpublish hoặc thuộc category inactive không xuất hiện trong response.
  - **V17**: API lỗi hiển thị trạng thái lỗi rõ ràng (alert role + nút Thử tải lại), không tự động fallback về dữ liệu mock giả.
  - Public response không chứa trường nội bộ hoặc cờ admin.
  - Home và Menu đồng bộ nguồn dữ liệu catalog từ database thật.
  - Cấu hình cache `max-age=30, stale-while-revalidate=60` hoạt động trên cả menu và settings.
