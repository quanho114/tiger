## Thay đổi contract / quyết định

- RPC `public.create_order` được mở rộng tham số `p_delivery_context jsonb` chứa `{ customer_name, customer_phone, address, delivery_zone_id, expected_shipping_fee_vnd }`.
- Khóa `v_zone_name_snapshot` được tách thành biến `text` riêng biệt để tránh lỗi runtime PL/pgSQL khi evaluate tuple record trên các đơn dine-in.
- Lỗi `P0021` từ database được chuẩn hóa thành mã lỗi `ZONE_UNAVAILABLE` với HTTP status 409.
- Định dạng error envelope hỗ trợ cả `details` và `field_errors` để duy trì tính tương thích ngược với API contracts.

## Chưa xong / rủi ro / external dependencies

## Rollback và bàn giao

- Để tạm dừng tính năng giao hàng trong trường hợp khẩn cấp: cập nhật setting trong cơ sở dữ liệu `UPDATE public.restaurant_settings SET accepting_delivery_orders = false WHERE id = 1`. Hệ thống sẽ lập tức từ chối nhận đơn giao hàng mới với thông báo rõ ràng mà không làm gián đoạn phục vụ tại bàn (`dine_in`).
