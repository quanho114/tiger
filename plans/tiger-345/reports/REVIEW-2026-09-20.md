## Findings

### F01 — P1: Edge Functions chưa có HTTP entrypoint chạy được

`supabase/functions/public-api/index.ts:1201` chỉ default export handler. Admin/customer entrypoints
cũng chỉ export, không Deno.serve/serve registration. Imports local dùng .js trong khi repo chỉ có
.ts; chưa có Deno import map/runtime setup cho deployment này. `package.json:10` gọi Node TypeScript
compiler, không Deno check như bảng báo cáo. Node integration import handler không chứng minh
Edge Runtime start hoặc gateway/auth behavior. Cần entrypoints runtime thực, module resolution
đúng, cấu hình guest gateway và HTTP smoke qua `functions/v1/*` thật trước nghiệm thu.

### F02 — P1: Customer đọc được internal_note qua PostgREST

`supabase/migrations/20260919000002_customer_identity_and_policies.sql:291` và :323 cấp SELECT
own order/reservation qua row policy. Table SELECT privileges vẫn có cả internal_note;
history policy :310 cũng không lọc actor_admin_id/reason. DTO an toàn của customer-api không
ngăn caller gọi thẳng REST table. Đã xác minh read-only trên DB local: authenticated có SELECT
internal_note ở cả orders/reservations và hai ownership policies đang active. Revoke direct reads
hoặc projection/column grants đúng; test raw REST select internal fields bằng customer JWT.

### F03 — P1: Admin login bị chính RLS chặn

`src/features/admin/auth/AdminLoginPage.tsx:49` và `src/features/auth/AuthProvider.tsx:41`
đọc admin_profiles trực tiếp bằng browser authenticated client. DB local có RLS nhưng không có
SELECT policy nào cho admin_profiles (đã query pg_policies). Kết quả rỗng khiến login signOut
ở :60, AuthProvider fallback customer. Cần authenticated admin identity endpoint hoặc self-read
projection hẹp; không mở danh sách admin cho public. Test login thật không intercept profile response.

### F04 — P1: HTTP client tự thay giờ hệ thống để qua kiểm tra lịch

`supabase/functions/_shared/schedule.ts:20` chấp nhận X-Test-Now từ request không kiểm môi trường.
`public-api/index.ts:853` dùng checker này khi create delivery. RPC create_order không kiểm lịch
business_hours/closures. Caller chọn giờ/ngày đang mở để đặt lúc đóng cửa hoặc ngày nghỉ.
Clock injection phải qua test context trusted, không HTTP header production; validate lịch trong
transaction hoặc bảo đảm rules atomic. Checker hiện cũng dùng closure 'all' thay restaurant closure
bao phủ mọi service như contract; bổ sung test restaurant-closed/delivery-open.

### F05 — P1: Xóa account mất tombstone trước khi Auth bị thu hồi

`supabase/migrations/20260920000008_account_deletion_and_retention.sql:191` xóa profile trước
Auth delete. `supabase/functions/_shared/auth.ts:81` chỉ chặn nếu profile tồn tại và deleting;
profile đã mất thì vẫn return customer. getPublicActor cũng không kiểm deletion.
Khi Auth delete lỗi, token vẫn được chấp nhận và có thể tạo giao dịch mới. Handler :1407 trả
“đang hoàn tất trong nền” nhưng chưa tìm thấy worker thực thi retry Auth delete; job record không
tự chạy. Cần tombstone/job gate độc lập, deny missing profile, block cả optional-auth mutations,
worker retry có bằng chứng và test lỗi Auth sau DB cleanup.
