login/account-switch/logout replies, review focus, keyboard handoff into a nonempty
cart and storage leakage. Added canonical workflow, memory controls, circuit/lease,
price-change-twice, summary/context, provider payload and cart replay/storage tests.

Legacy transaction fixtures now explicitly use all-day delivery, so regression
results do not depend on crossing 21:30 while running. The final rerun also
exposed restaurant closure after 22:30: six fixture files now explicitly keep
restaurant/delivery service open for transaction tests. Full integration then
passed all 350 tests. Production schedule logic is unchanged. HTTP smoke restores original
hours. The closed-hours assertion accepts either valid kitchen or delivery closure
while retaining the SQL error code assertion. Admin-login URL assertion now requires
`/admin`, excluding `/admin/login`.
