# V13 - Idempotent cart handoff

Status: DONE (implementation and local verification; release gates remain separate)

## Scope and dependencies

Implements the assigned task in the user-authorized full V2 plan, preserving the current feature-based repository architecture. Acceptance: A03, A10-A13, A18.

## Changes

- `cart-handoff.ts` exports one reviewed version with a five-minute opaque handoff ID, actor/session/version checks, and fresh catalog/mode/allergy validation. Retries return the same snapshot.
- Blocked rows retain old quantities/prices and show the new price explicitly; accept_prices compares the displayed price with current catalog again. No-allergy requests use not_requested, never a fabricated verified_safe label.
- `src/features/cart/handoff.ts` merges normal cart lines plus dedup ID atomically. Existing notes/items survive, including manual edits batched in the same event. Required storage failure rejects the handoff and leaves UI retryable.
- Checkout remains the existing user-confirmed flow. Exported sets require explicit start_new_set, preventing silent re-export.
