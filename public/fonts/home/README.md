# Homepage fonts

WOFF2 files downloaded from the official Google Fonts CSS API on 2026-10-23.
Included subsets: Latin, Latin Extended, Vietnamese.

- Be Vietnam Pro: 400, 600, 700, 800
- Dancing Script: 500, 600
- Noto Serif: 700, 800
- Fraunces: 700

The accompanying OFL files are from google/fonts. CSS aliases in HomeFonts.css
keep these self-hosted faces scoped to the homepage, its header and navigation.
The assistant UI continues to use its existing font configuration.
